# AA NotMischef (v4)

Anime Adventures macro (AutoHotkey v2 + Python vision helper).

- First time on a PC: run `Setup (first time).bat`, then start `Main.ahk`.
- Only the macro's **code** lives here. Each PC keeps its own `Settings` and `Logs` (never uploaded).
- Updates: on start-up the macro compares `VERSION.txt` with this repo and asks before updating
  (`Settings\AutoUpdate.txt`: `Ask` / `Auto` / `Off`). The previous code is kept in `Backup (before update ...)`.
